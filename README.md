# Живая Земля (демо)

Интерактивная 3D-сцена планеты Земля с приближением от космического масштаба до условного уровня ~1 метр.

## Что реализовано

- Фотореалистичная текстурированная Земля (день, рельеф, блики океанов, облака, атмосфера).
- Управляемая камера OrbitControls для плавного зума и вращения.
- Явные элементы управления: кнопки зума и передвижения, плюс горячие клавиши `W/A/S/D`, `+/-`, `R`.
- Поиск по имени (города и природные точки) с автофокусом на выбранной локации.
- Три уровня детализации (LOD):
  - Космический обзор.
  - Региональный обзор.
  - Поверхностный обзор.
- Процедурные слои «живого и неживого»: люди, животные, растения, инфраструктура, геология.

> Важно: это технологическое демо. Полная модель «всех обитателей Земли в реальном времени» физически невозможна в рамках браузера и доступных открытых данных, поэтому используется иерархическая имитация с процедурной генерацией.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте в браузере: <http://localhost:8000>
